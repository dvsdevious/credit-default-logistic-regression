# credit-default-logistic-regression
Exploratory data analysis and logistic regression modeling using the Default of Credit Card Clients dataset to predict customer default risk.

Dataset
This project uses the Default of Credit Card Clients dataset from Taiwan. The original study compared six data mining techniques for estimating the probability of customer default. In this project, the focus is on exploratory data analysis and developing a logistic regression model to predict whether a customer will default on their credit card payment.
